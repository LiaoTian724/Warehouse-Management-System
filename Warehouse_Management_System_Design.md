# Warehouse Management System（WMS）项目设计

## 项目名称

Warehouse Management System（WMS）

技术栈：

-   后端：Django
-   数据库：开发 SQLite，部署 PostgreSQL
-   前端：Django Template + Bootstrap
-   部署：Docker + Nginx + Gunicorn

# 二、用户角色设计

## 1. 管理员 Admin

权限：

-   创建用户
-   删除用户
-   修改权限
-   禁用账号
-   创建物品
-   修改物品
-   删除/停用物品
-   添加库存
-   查看所有记录

------------------------------------------------------------------------

## 2. 普通用户 User

权限：

允许：

-   查看库存
-   借出物品
-   归还物品

禁止：

-   新建物品
-   修改物品属性
-   删除记录

------------------------------------------------------------------------

# 三、物品设计

不同品牌、型号认为不同物品。

例如：

    物品A:
    名称: 螺丝刀
    品牌: 德力西
    型号: DLX001
    数量:50


    物品B:
    名称: 螺丝刀
    品牌: 小米
    型号: X001
    数量:30

------------------------------------------------------------------------

# 四、数据库设计

## 1. User（用户）

使用 Django 自带 User。

字段：

-   id
-   username
-   password
-   permission
-   status

------------------------------------------------------------------------

## 2. Item（物品表）

存储物品基础信息。

字段：

  字段           说明
  -------------- ----------
  id             编号
  name           名称
  quantity       当前数量
  status         状态
  created_by     创建人
  created_time   创建时间

------------------------------------------------------------------------

## 3. Attribute（动态属性表）

解决不同物品具有不同属性的问题。

例如：

螺丝刀：

    品牌: 德力西
    型号: DLX001
    长度: 20cm

数据库：

  item   key    value
  ------ ------ --------
  1      品牌   德力西
  1      型号   DLX001
  1      长度   20cm

------------------------------------------------------------------------

## 4. StockRecord（库存流水表）

记录所有库存变化。

字段：

  字段       说明
  ---------- ----------
  user       操作用户
  item       物品
  type       操作类型
  quantity   数量
  purpose    用途
  time       时间

类型：

    IN
    入库

    OUT
    借出

    RETURN
    归还

例如：

    张三
    螺丝刀
    OUT
    2
    维修
    2026-09-02

------------------------------------------------------------------------

## 5. InventoryAlert（库存预警）

增加最低库存设置。

例如：

    螺丝刀

    当前:
    5

    最低:
    10

显示：

    库存不足

------------------------------------------------------------------------

# 五、核心业务流程

## 场景1：新物品入库

管理员：

新增物品：

    名称:
    螺丝刀

    数量:
    50

添加属性：

    品牌:
    德力西

    型号:
    001

系统生成：

-   Item记录
-   Attribute记录
-   StockRecord入库记录

------------------------------------------------------------------------

## 场景2：用户借出

用户选择：

    物品:
    螺丝刀

    数量:
    2

    用途:
    维修

系统：

检查库存：

    库存 >= 借出数量

更新：

    50 -> 48

生成流水记录。

------------------------------------------------------------------------

## 场景3：归还

用户归还：

    数量:
    2

库存：

    48 + 2 = 50

生成归还记录。
